Experimental — expect a very low frame rate

Broadcasting from this browser is experimental and buggy, and it very likely gives you very low FPS. This page has to capture, encode and upload the video on the same machine at the same time. The preview above plays the raw screen capture, not the encoded stream, so it keeps looking smooth while the real broadcast is struggling — watch the FPS and Resolution meters, not the preview. For a real broadcast, use OBS Studio over WHIP instead — it is stable and holds full frame rate:

  1. In OBS open Settings → Stream and set Service to WHIP.
  2. Set Server to http://127.0.0.1:8889/live/whip and leave the Bearer token empty.
  3. Under Output → Streaming: encoder NVENC AV1 (or NVENC H.264), rate control CBR, keyframe interval 1 second, Max B-frames 0, and disable Look-ahead.
  4. Click Start Streaming. WHIP is also the only OBS path that carries sound natively (Opus), so viewers hear audio.

Both paths publish to the same live stream, so a viewer sees one stream either way — but the browser path is far likelier to stutter. The full settings list is on the watch page.
