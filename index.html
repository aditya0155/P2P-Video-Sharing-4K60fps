OBS Studio Settings

Select ingest protocol for OBS Studio setup:

  • ServiceCustom...
  • Serverrtmp://127.0.0.1:1935/live
  • Stream KeyLeave empty
  • AudioRTMP audio is AAC, which MediaMTX cannot convert for WebRTC — viewers hear nothing. Use the WHIP option in the next tab when you need sound.
  • EncoderStart with H.264; test other codecs on each browser
  • Rate ControlCBR
  • BitrateKeep about 25% of stable hotspot upload free
  • Keyframe Interval2 seconds
  • Max B-framesTry 0 if viewers see decoder issues
  • Look-aheadDisable to prioritize low latency
  • SRT Ingestsrt://127.0.0.1:8890?streamid=publish:live
  • WHIP Ingesthttp://127.0.0.1:8889/live/whip
  • Audio (recommended)WHIP is the only OBS path that delivers sound: it publishes Opus, while RTMP/SRT carry AAC which WebRTC players cannot receive. In OBS choose Service: WHIP, set Server to the URL above, and leave Bearer Token empty.
  • Encoder InfoUse CBR and a 2-second keyframe interval; test playback before a long session.

About WebRTC & WHEP

Playback uses WebRTC through WHEP. The header reports the resolution, frame rate, and bitrate measured from the active stream; values depend on the broadcast and your connection.

Smooth Playback Tips

For steadier playback:

  • Hardware GPU DecodeEnsure Hardware Acceleration is turned ON in your browser settings.
  • Decoder compatibilityIf playback fails, try H.264 and set B-frames to 0.
  • Frame pacingMatch the capture and display frame rates where practical.
  • OBS Pacing LockCheck "Limit capture framerate" in Game Capture source settings.
