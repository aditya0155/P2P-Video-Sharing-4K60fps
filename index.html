OBS Studio Settings

Select ingest protocol for OBS Studio setup:

  • ServiceCustom...
  • Serverrtmp://127.0.0.1:1935/live
  • Stream KeyLeave empty
  • AudioRTMP audio is AAC, which the WebRTC path cannot read directly — the host bridge automatically converts it to Opus on a full-quality rendition, so viewers hear sound. WHIP (next tab) delivers Opus natively.
  • EncoderNVIDIA NVENC AV1 (best for low bandwidth) or NVENC H.264 — both are served to every browser automatically
  • Rate ControlCBR
  • BitrateKeep about 25% of stable hotspot upload free
  • Keyframe Interval1 second — 2s makes keyframes huge and loss recovery slow, which viewers feel as stutter
  • Max B-frames0 — required: WebRTC cannot play H.264 with B-frames, viewers get disconnected instantly
  • Look-aheadDisable to prioritize low latency
  • Auto renditionsThe host bridges your stream to the other codec on the GPU (AV1 source → live-h264, H.264 source → live-av1), so every browser plays regardless of codec support.
  • SRT Ingestsrt://127.0.0.1:8890?streamid=publish:live
  • WHIP Ingesthttp://127.0.0.1:8889/live/whip
  • Audio (recommended)WHIP is the only OBS path that delivers sound: it publishes Opus, while RTMP/SRT carry AAC which WebRTC players cannot receive. In OBS choose Service: WHIP, set Server to the URL above, and leave Bearer Token empty.
  • Encoder InfoNVENC AV1 or H.264 with CBR and a 1-second keyframe interval; test playback before a long session.

About WebRTC & WHEP

Playback uses WebRTC through WHEP. The header reports the resolution, frame rate, and bitrate measured from the active stream; values depend on the broadcast and your connection.

Smooth Playback Tips

For steadier playback:

  • Hardware GPU DecodeEnsure Hardware Acceleration is turned ON in your browser settings.
  • Decoder compatibilityIf playback fails, set Max B-frames to 0 first (WebRTC cannot decode H.264 with B-frames), then try H.264.
  • Frame pacingMatch the capture and display frame rates where practical.
  • OBS Pacing LockCheck "Limit capture framerate" in Game Capture source settings.
